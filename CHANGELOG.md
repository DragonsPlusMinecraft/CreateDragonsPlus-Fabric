# 1.11.4-fabric.1

- Ported Create: Dragons Plus directly to Fabric 1.20.1 with Fabric Transfer and Create Fabric 6.0.8.1.
- Preserved the `create_dragons_plus` mod ID, registry IDs, config keys, language keys, and runtime recipe behavior.
- Added optional JEI 15.20 integration for Bulk Coloring, Freezing, Sanding, Ending, catalysts, and dynamic Mixing recipes.
- Added optional Dye Depot and Arts & Crafts integrations.
- Added deterministic Fabric datagen, migration residue checks, GameTests, client smoke tests, and Fabric publishing workflows.
- Dyenamics, Create: Garnished, Immersive Engineering, REI, and EMI are not supported by this first Fabric release.
